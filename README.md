
# SC Hotel AI Booking System

**AI-Powered Hotel Booking and Management Web Application**

## Project Overview

SC Hotel AI Booking System is a web-based application designed to simplify hotel reservation and management processes. It provides guests with an online booking platform and an AI-powered chat assistant for hotel-related inquiries.

The system also includes administrative features for managing bookings, rooms, users, and other hotel operations.

## Live Application

- **Live Website:** https://schotel.kesug.com/
- **GitHub Repository:** https://github.com/kenneth353/SC_Hotel1

## Features

- Online hotel room booking
- User registration and authentication
- Room information and management
- Booking and reservation management
- AI-powered hotel chat assistant
- Email integration using PHPMailer
- ID and selfie submission for identity verification
- Administrative dashboard
- MySQL database integration

## Installation and Setup

### Requirements

- XAMPP
- PHP
- MySQL
- Web browser
- Internet connection for external API services

### Local Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kenneth353/SC_Hotel1.git
   ```

2. Place the project folder inside the XAMPP `htdocs` directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Create the required database using phpMyAdmin.

5. Import the project's SQL database file, if available.

6. Configure the database connection and required API credentials.

7. Open the application:

   ```text
   http://localhost/SC_Hotel1/
   ```

## Security

- Keep database credentials and API keys private.
- Do not commit sensitive configuration files.
- Protect uploaded identity documents and personal information.
- Configure credentials securely in the deployment environment.
